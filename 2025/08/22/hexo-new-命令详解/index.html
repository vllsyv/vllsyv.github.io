hexo new 命令详解

2025年08月22日
0
教程
hexo ， 教程

hexo new 命令是我们创建新内容的基础工具。虽然表面上看起来只是一个简单的命令，但它实际上支持多种不同的参数和选项，能够帮助我们创建不同类型的内容，包括正式发布的文章、独立页面以及暂存的草稿。

Hexo new 命令详解

1. hexo new "文章标题"

这是最常用的命令，用于创建一篇新的博文。

  • 类型： post (文章)
  • 存储位置： source/_posts/文章标题.md
  • 说明： 这是 hexo new post "文章标题" 的简写形式，两者完全等效。创建的文件会直接存放在 _posts 文件夹下，在执行 hexo generate 时，该文章会被处理并发布到您的网站。

使用场景： 撰写需要立即发布的正式博客文章。

2. hexo new post "文章标题"

此命令与第一条命令完全一样。

  • 类型： post (文章)
  • 存储位置： source/_posts/文章标题.md
  • 说明： 明确指定了布局（layout）为 post。功能和使用场景与 hexo new "文章标题" 没有任何区别。

3. hexo new page "页面名称"

此命令用于创建一个独立页面，如“关于”、“归档”、“友情链接”等。

  • 类型： page (页面)
  • 存储位置： source/页面名称/index.md
  • 说明： 它会在 source 目录下创建一个以页面名称命名的新文件夹，并在其中放置一个 index.md 文件。这个页面不会出现在文章列表或归档中，而是作为一个独立的页面存在。你需要手动在主题的导航栏配置中添加链接指向它（例如 yourdomain.com/about/）。

使用场景： 创建“关于我”、“联系方式”等独立于文章流的内容。

4. hexo new draft "草稿标题"

此命令用于创建一篇草稿。

  • 类型： draft (草稿)
  • 存储位置： source/_drafts/草稿标题.md
  • 说明： 草稿文件会被存放在 _drafts 目录下。在执行 hexo generate 或 hexo deploy 时，草稿不会被处理或发布到网站。这允许你保存未完成的文章，而不用担心它被意外发布。

使用场景： 保存尚未完成、还需要修改或暂时不想公开的文章。

总结与类比

命令 类型 存储位置 是否发布 类比
hexo new "文章标题" 文章 (post) source/_posts/ 是 正式发表的论文
hexo new post "文章标题" 文章 (post) source/_posts/ 是 正式发表的论文（同上）
hexo new page "页面名称" 页面 (page) source/页面名称/ 是 网站的“关于我们”页面
hexo new draft "草稿标题" 草稿 (draft) source/_drafts/ 否 放在抽屉里的未完成的手稿

如何发布草稿？

当你完成草稿的撰写后，可以使用 publish 命令将其“移动”到正式文章（_posts）目录中，之后它就会被正常发布。

hexo publish draft "草稿标题"
