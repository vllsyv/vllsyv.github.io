将秘钥添加至github

点击右上角你的头像，选择 Settings。
在左侧边栏中，点击 SSH and GPG keys。
点击绿色的 New SSH key 按钮。
在 “Title” 中，为这个密钥起一个容易识别的名字（例如：My Personal Laptop）。
在 “Key” 字段中，粘贴你刚才复制的公钥内容。
点击 Add SSH key。

22端口无法访问

执行ssh -T git@github.com，返回ssh: connect to host github.com port 22: Connection refused
使用 SSH over HTTPS

你的计算机无法通过 SSH 的默认端口（22）连接到 GitHub 服务器。这通常是由于网络限制引起的，比如防火墙、公司/学校网络策略，或者你所在的网络环境屏蔽了端口 22。
GitHub 的 SSH 服务在端口 443 上也是可用的。我们可以修改 SSH 配置，让所有与 GitHub 的 SSH 连接都通过这个端口进行。

  1. 打开或创建 SSH 配置文件：
    在你的用户主目录下的 .ssh 文件夹中，有一个名为 config 的文件（没有扩展名）。如果不存在，请创建它。
  2. 添加以下配置内容。将以下文本复制粘贴到配置文件中并保存：

Host github.com: 表示这些设置只对连接到 github.com 生效。
Hostname ssh.github.com: 这是 GitHub 为 SSH over HTTPS 提供的特定主机名。
Port 443: 指定使用 HTTPS 端口（443）而不是默认的 SSH 端口（22）。
User git: 所有 GitHub 的 SSH 连接都使用 git 用户。
