2025年08月21日
0

hexo ， 安装实操

用 GitHub 免费搭建个人博客是个很棒的选择。
GitHub Pages 提供稳定、免费的托管服务，支持自定义域名和 HTTPS，非常适合技术写作和个人展示。
下面是一份比较主流和推荐的搭建流程概要，我会以 Hexo 这个快速、简洁且强大的静态博客框架为例，因为它对新手比较友好，生态丰富

🛠 准备工作

注册 GitHub 账号：

访问GitHub 官网，点击 “Sign up” 完成注册。
如果无法访问，可以尝试修改dns，或者使用加速器，如watt toolkit

安装 Node.js：

Hexo 基于 Node.js。请从 Node.js 官网下载并安装 LTS（长期支持版）。 安装成功后，在终端输入 node -v 和 npm -v 检查版本。

🚀 部署到 GitHub Pages

创建 GitHub 仓库：

在你的 GitHub 主页点击 “New repository”。
仓库名必须严格遵守格式：你的GitHub用户名.github.io（例如，如果你的用户名是 john，则仓库名应为 john.github.io）。这一点非常重要，否则无法通过默认域名访问。
选择仓库可见性为 Public（公开）。
